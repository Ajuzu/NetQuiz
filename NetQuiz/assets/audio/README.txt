ASET AUDIO NETQUIZ
==================
Semua file di folder ini dibuat sendiri lewat sintesis kode (gelombang sinus/bel/pad),
tanpa sampel pihak ketiga, sehingga bebas hak cipta (dilepas sebagai CC0 / domain publik).
Boleh dipakai, diubah, dan didistribusikan tanpa atribusi.

Fungsi tiap file
  click.wav     suara tombol ditekan
  correct.wav   jawaban benar
  wrong.wav     jawaban salah
  gameover.wav  nyawa habis (game over)
  complete.wav  quiz selesai
  bgm.wav       musik latar (di-loop, dikontrol tombol "Musik" di Dashboard)

Cara mengganti
  1) Timpa file dengan audio baru bernama sama (format .wav / .mp3 / .ogg), ATAU
  2) Ubah nama file / volume di tabel SFX dan BGM pada <script> "Modul audio NetQuiz"
     di index.html (cari kata "MENGGANTI AUDIO").
  Catatan: untuk musik latar, gunakan file yang loop-nya mulus. Format .wav paling aman
  (MP3 menambah jeda kecil di titik loop).

Sumber bebas hak cipta yang disarankan: kenney.nl/assets (CC0), freesound.org (filter CC0),
pixabay.com/music, opengameart.org (cek lisensi tiap file).
